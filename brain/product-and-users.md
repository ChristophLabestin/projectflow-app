# Product and Users

Last updated: 2026-06-04

## Primary Audiences

- B2B software companies and digital product teams.
- Founders, startup operators, and company-building teams.
- Freelancers and solo operators who need structured execution.
- Cross-functional product, engineering, marketing, design, and growth teams.

## Core User Journeys

- Create a tenant/workspace and manage members.
- Create projects with module configuration and lifecycle state.
- Manage tasks, subtasks, issues, Flows, milestones, and optional modules.
- Invite workspace members or external project collaborators with correct access boundaries.
- Use AI assistance within tier and quota limits.
- Track Codex coding work as ProjectFlow sessions, follow-ups, and project context.
- Use mobile/iOS surfaces for focus, capture, share sheet import, widgets, and notification-driven workflows.

## Value To Preserve

- Execution and ideation live together instead of being split across unrelated tools.
- Access control stays understandable and enforceable.
- Project state remains truthful across web, iOS, notifications, and Codex automation.
- The system supports both software-delivery projects and broader company/startup project types.

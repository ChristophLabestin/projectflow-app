# Session Note Template

## Why this file exists
Provide a reusable template for detailed work-session notes when a session deserves more detail than the session log.

## How to use it
- Update this file when the session-note structure should improve.
- Avoid using it for storing project-specific live state directly in the template.
- Prefer concise, concrete statements over long narrative.

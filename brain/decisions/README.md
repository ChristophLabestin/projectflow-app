# Decisions Folder Guide

## Why this file exists
Explain how to store deeper ADR-style decision records when a short log entry is not enough.

## How to use it
- Update this file when the team changes how it writes or stores decision records.
- Avoid using it for putting live decisions here without linking them from the decision log.
- Prefer concise, concrete statements over long narrative.

## Context
- Project: projectflow-app
- Project type: app
- Scaffolded: 2026-06-04
- Last updated: 2026-06-04
- Status: Draft

## When to Create a Decision Record
- Use this folder when a decision has real tradeoffs, alternatives, or long-term consequences.

## Naming
- Use a stable, sortable name such as `2026-04-27-decision-name.md`.

## Linking
- Add a short entry in `../decision-log.md` and link to the detailed record.

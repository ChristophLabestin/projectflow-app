# Sessions Folder Guide

## Why this file exists
Explain how to keep deeper session notes without turning core files into archives.

## How to use it
- Update this file when the session-note workflow changes.
- Avoid using it for using this folder as a substitute for updating current-focus or handoff.
- Prefer concise, concrete statements over long narrative.

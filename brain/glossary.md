# Glossary

Last updated: 2026-06-04

## Terms

- Brain: the living knowledge base under `brain/`; replaces scattered root Markdown and the old `docs/` folder.
- Tenant: top-level workspace/company/team entity.
- Workspace member: user who belongs to a tenant and may occupy a licensed seat.
- External collaborator: project-scoped user who does not become a tenant member.
- Project: unit of work under a tenant; can be a product, client project, internal initiative, or company/startup founding effort.
- Flow: ProjectFlow's structured ideation and pipeline feature.
- Module: project-configurable capability such as Tasks, Issues, Social, Marketing, Sprints, or Accounting.
- Codex session: tracked coding work linked back into ProjectFlow through the repo-local plugin/API.
- Initiative: larger ProjectFlow work container for major features, migrations, or multi-subsystem work.
- ProjectFlow project id: this repository's linked tracking project is `ogZ8Pyz8pwEQtv8I64nu`.

## Naming Notes

- Brain core files use lowercase kebab-case.
- Migrated legacy docs under `brain/reference/app/` currently preserve their old uppercase names to reduce link churn.
- Component files use PascalCase.
- Hooks use `useX`.
- SCSS files use kebab-case.
